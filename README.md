# 🚛 FleetFuel
<img src="./assets/dashboard.png" width="800">
Sistema de gerenciamento e controle de combustível para frotas.

O FleetFuel foi desenvolvido para facilitar o acompanhamento de abastecimentos,
consumo médio, custos e desempenho dos veículos de uma empresa.

## 🚀 Funcionalidades

- ✅ Cadastro de veículos
- ✅ Controle de abastecimentos
- ✅ Cálculo de consumo médio
- ✅ Controle de gastos
- ✅ Dashboard de indicadores
- 🔄 Relatórios de desempenho (em desenvolvimento)

## 🛠️ Tecnologias utilizadas

### Frontend
- React
- Vite
- JavaScript
- CSS

### Backend
- Node.js
- Express
- Prisma ORM

### Banco de dados
- PostgreSQL
